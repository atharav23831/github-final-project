# Simple Interest Calculator

A Bash script designed to calculate simple interest based on user inputs.

## Description
This project calculates simple interest using the formula:
Simple Interest = (Principal * Rate of Interest * Time) / 100

## Input Parameters:
- **p / Principal**: The initial amount of money invested or borrowed.
- **t / Time**: The time period in years.
- **r / Rate**: The annual rate of interest.

## Output:
- **Simple Interest**: The calculated interest amount.

## Usage:
Run the script in a bash terminal:
```bash
./simple-interest.sh
